Load the master operator list

Pick your master .xlsx — the one with a sheet per site. Each sheet becomes a site; the CODE NO. / NAME / FATHER NAME / ACCOUNT NUMBER / IFSC CODE columns are read automatically. Loading it again later updates operators by code and keeps everything else.

Opening this console on another computer or browser? You don't need any files — go to the ☁ Cloud & links tab, enter the Web app URL and admin key, and press Load everything from the sheet.

Sites

Supervisors

Add each supervisor once and tick the sites they cover. A supervisor can hold any number of sites, and a site can be shared between supervisors if two men genuinely work it — you'll be warned when that happens so it isn't done by mistake.

Or load them all from Excel

Two columns is all it needs: SUPERVISOR NAME and SITES. Sites can be comma-separated in one cell, or spread across extra columns headed SITE 2, SITE 3 and so on — both work. Trailing OK in a site name is ignored. Existing supervisors are matched by name and updated. A PHONE column is read if present, but is not required.

Issue setup files

Each file carries only that supervisor's sites and operators. Send it to him on WhatsApp; he opens the app, taps ☰ → Load my setup file, and he's ready. Re-issue any time — WD already typed for a site he keeps is preserved.

Merge the returned files

Select every workbook the supervisors sent back — all at once. They're combined into one master file, a sheet per site, in your usual column order. Sites you assigned but never received are listed so you know exactly who to chase.

Connect to your Google Sheet

Paste the Web app URL from Apps Script (it ends in /exec) and the ADMIN KEY that setUp() printed. Both are stored in this browser only and are never put in the app itself.

Load pulls the master list down from the sheet — use it on a new computer or browser. Upload pushes what is on this screen up to the sheet, replacing what is there.

config.js is the one file the app needs in order to find your sheet. Download it and upload it to your repo (or Netlify) alongside index.html. Without it the app stays in offline setup-file mode.
